# game-insights

게임 기획자 관점의 **일일 칼럼**과 **게임 분석서**를 AI 자동화 + 사람 검증 분업으로 축적하는 저장소.

## 분업 구조

| 단계 | 담당 | 내용 |
|---|---|---|
| 수집 | AI (매일 05시 KST 자동) | 국내외 게임 매체·리뷰·지표 수집, 출처 링크 기록 |
| 검증 | AI | 2개 이상 출처 교차 확인, 미확인 사항은 `⚠ 미확인` 표기 |
| 초안 | AI | 칼럼 본문 / 분석서 초안 + 기획자 우선 분석 포인트 |
| 검토·플레이 | 사람 | 아침 검토, 직접 플레이, `[사람 작성]` 섹션 채움 |
| 확정 | 사람 | frontmatter `status`를 `done`으로 변경 |

## 폴더

```
columns/    YYYY-MM-DD-slug.md   매일 1건 칼럼
analyses/   YYYY-MM-DD-slug.md   주 1~2건 게임 분석서 (초안 → 플레이 → 완성)
templates/  column.md, analysis.md
log/        journal.md           AI 협업 일지 (매 실행마다 append)
queue.md                          사람이 우선 분석을 원하는 게임 대기열
ROUTINE.md                        클라우드 예약 에이전트 프롬프트 원문
```

## 상태 흐름

`draft`(AI 초안) → `playing`(플레이 중) → `done`(사람 완성). 칼럼은 `draft` → `done`.

## 분석 대상 선정 규칙 (AI 자동 선정)

1. **플랫폼 필터**: PC(Steam) 또는 모바일(iOS/Android)에서 플레이 가능해야 함. 유료 게임 허용. 콘솔 독점작 제외.
2. **최신성**: 최근 2주 내 출시, 또는 대형 업데이트·급격한 반응 변화가 있는 게임.
3. **교차 신호**: 아래 소스 중 **2개 이상**에서 상위권/급상승에 동시에 잡힌 게임만 후보.
   - Steam: 최다 동시접속, 최고 판매, 최근 리뷰 급증
   - Metacritic / OpenCritic 신작 평점
   - 한국 앱스토어·구글플레이 매출/인기 순위
   - 커뮤니티 언급량: 인벤, 루리웹, 디스이즈게임즈, Reddit r/games
4. **교대 배치**: 직전 분석이 대형작이면 이번엔 인디·다크호스, 반대도 동일. `analyses/` 파일의 `tier` 값으로 판단.
5. **중복 방지**: `analyses/`에 이미 있는 게임과 같은 프랜차이즈는 6개월간 제외.
6. **우선 대기열**: `queue.md`에 항목이 있으면 자동 선정보다 먼저 처리.

## 칼럼 소재 선정 규칙

- 소스: 디스이즈게임즈, 인벤, 게임메카, GamesIndustry.biz, Game Developer, PC Gamer, IGN, Kotaku, Steam 뉴스.
- 기준: 당일~2일 내 보도, **기획적으로 논할 거리**가 있는 이슈 우선(시스템 변경, BM 논란, 밸런스 패치, 신작 반응, 업계 트렌드). 단순 출시 공지·인사 소식 제외.
- 기사 본문은 저장하지 않고 **요약 + 출처 링크**만 남김.

## 아침 검토 루틴 (사람)

1. `git pull` 후 `log/journal.md` 최신 항목 확인 (AI가 자신 없다고 표시한 지점 우선).
2. 칼럼: 팩트체크 표의 `⚠ 미확인` 항목 확인, 의견 수정 후 `status: done`.
3. 분석서: 선정 근거 납득되면 플레이 시작, `[사람 작성]` 섹션 채움.
4. 다음 분석 희망 게임이 있으면 `queue.md`에 추가.
