- **가격**: **₩69,800** (정가, 할인 없음) [1]. 인앱 구매 카테고리 없음 [1][3]. **별매 DLC: 'Football Manager 27 게임 내 에디터' $8.99** [3], **무료 데모 제공** [3].

- **한국어**: **인터페이스만 지원**. 음성·자막은 지원표에 체크되어 있지 않다(총 20개 언어 지원) [3]. 텍스트량이 극단적으로 많은 장르인데 UI 번역만 있다는 뜻이며, 실제로는 FM 시리즈 특성상 인터페이스 번역이 사실상 전부다 — ⚠ 다만 "뉴스·기자회견·선수 대화" 텍스트가 번역 범위에 포함되는지는 지원표만으로 판단할 수 없다.
- **공식 소개 요약** (Steam 상점 "게임에 대해" 기반 [3]): "구단을 선택하고, 선수단을 꾸리고, 전술을 정하자."로 시작한다. 본문이 내세우는 항목은 **1,500개 이상의 대회 업데이트, 새로운 공식 라이선스 리그, 향상된 2D 경기 화면, 전술 효율성(Tactical Effectiveness) 측정, 개편된 훈련 시스템**이다 [3].

**전작(FM26) 배경 — 이 작품의 평가 기준선.** FM26은 2025-11-04 출시로 **시리즈 최초 Unity 엔진 전환작**이었고, FM25가 2025년 2월 "내부 품질 기준 미달"로 취소된 뒤 2년 만에 나온 작품이다 [14]. 게임메카는 FM26을 두고 **"일부 작업에 3번 이상 클릭이 필요한 UI, 화면 전환 지연, 다수 버그"**로 비판받고 **"데이터 분석 도구와 터치라인 지시가 삭제"**됐으며 **"시리즈 최악"**이라는 혹평을 받았다고 정리했다 [11]. Metacritic 기준으로도 시리즈 최저 평점이었다 [14]. FM27은 그 구멍을 메우는 작품으로 설계됐다.

4. **전술·훈련 연동이 선택의 무게를 키웠다.** 인벤 기사는 "전술·훈련·선수단 관리의 연결이 강해져 감독의 선택에 무게가 생겼다"고 정리했고 [10], GamingBolt는 "전술과 훈련 변경이 의사결정을 더 중대하게 느끼게 한다"고 평가했다 [6]. 한국어 추천 리뷰 5번도 **새 전술 효율성 자체는 마음에 든다**고 명시했다 [13].
5. **중독성·장시간 체류.** 표본의 플레이타임이 이미 극단적이다 — 추천 리뷰에 188.9시간·189.0시간·118.9시간(한국어)이 있고, 출시 7일 만의 기록이다 [12][13].

**부정 Top 5**

1. **경기 엔진 — 단일 최대 불만이고, 서술이 서로 일치한다.** "the match engine experience has regressed" (비추천, 74.7시간), 스트라이커 오프사이드 빈발·먼 거리 슛이 너무 잘 들어감 [12]. "diabolical" + 형편없는 수비·오프사이드 골·과도한 경고 (비추천, 118.4시간) [12]. **추천** 리뷰 3번도 **골대 강타와 오프사이드 골이 너무 많다**고 적었다 [12]. 게임메카가 집계한 유저 불만도 동일하다 — **"수비 AI가 상대를 무시하는 경향, 오프사이드 빈발, 골대 강타, VAR 연출 오류"** [11]. 한국어 리뷰 1번은 **자책골 빈발·과도한 카드**를 지적했다 [13].
2. **전술 효율성이 '시즌 중 전술 변경'을 봉쇄한다 — 이 문서의 핵심 쟁점.** 한국어 추천 리뷰 5번: **"이거 때문에 시즌 중에 전술을 바꿀 수가 없다."** + 그로 인한 **감독 경질 연쇄**를 우려 [13]. 한국어 비추천 리뷰 1번: **"내가 원하는 전술을 선수단에 입히는 시간이 심각할 정도로 느림"** [13]. 영어 비추천 리뷰 7번: **"Tactical Effectiveness seems to be all that matters in this game."** [12] → **3명이 서로 다른 언어·추천 성향에서 같은 지점을 지적했다.**
3. **"FM24 수준의 완성도에는 못 미친다" — 기준점을 FM26이 아니라 FM24로 잡는 반발.** "FM27 is an improvement over FM26, but it still doesn't come close to the polish of FM24" (비추천, 24.0시간) [12]. 비추천 리뷰 10번은 더 직접적으로 **"I refuse to call this a comeback or a return to form for the series."**라며, FM26보다 나아진 것이 FM27을 좋은 게임으로 만들지는 않는다고 주장했다 [12]. **그 외 반복 언급**
- **경기 비주얼**: GamingBolt는 선수 모델이 "extremely primitive"하고 관중이 **"PS2 시절 스포츠 게임 수준"**이라고 했다 [6]. 반면 인벤 글로벌 리뷰는 **실시간 날씨·시간대 변화, 결과에 반응하는 관중, 강화된 페인트·몸싸움 애니메이션(실제 영상·신규 모캡 기반)**을 호평했다 [7] → **같은 대상에 평가가 정반대로 갈린다.**

- **신규 유저 진입장벽**: 한국어 리뷰 10번(12.0시간)은 **시스템이 많고 텍스트 기반 지시가 많아 재미를 붙이기 어렵다**며 입문 가이드 영상을 요청했다 [13]. 한국어 리뷰 3번(71.4시간)은 **하위 리그 팀도 강팀처럼 플레이해서 플레이어에게 핸디캡이 걸린 느낌**이라고 했다 [13].
- **위임 UX**: GamingBolt는 **감독 생성(manager creation)이 "super disappointing"**하고, **백룸 스태프 관리가 재미없어 수석코치에게 위임해 버렸다**고 적었다 [6]. 추천 리뷰 6번은 **유스 코치 통제권이 제한적**이라고 했다 [12].

## 핵심 시스템 가설 (⚠ 플레이로 확인 필요)

아래는 **리뷰·공식 자료·개발자 인터뷰로 추정한 것이며, 직접 플레이로 검증되지 않았다.**

- **코어 루프 (추정)**: `전술 설계 → 그 전술에 맞는 훈련 편성 → 전술 효율성 수치 상승 대기 → 경기 → 상대 대비 정보 반영 → 이적/영입으로 선수단을 전술에 맞춤`. 핵심은 **FM 전통의 루프에 '전술 효율성'이라는 게이트가 끼어든 것**이라고 본다. 인벤 글로벌 리뷰는 효율성이 **"전술 지시에 대한 선수들의 이해도를 종합 평가해 산출"**되며 **역할 적합도, 감독 철학과의 궁합, 경기 전 상대 정보**까지 반영한다고 설명한다 [7]. GamingBolt도 **"전술 철학을 영입·훈련·보유 선수와 연결하는 시스템"**으로 서술한다 [6].
- **전술 복잡도라는 역방향 코스트 (추정, 이 게임의 설계 심장이라고 본다)**: 인벤 글로벌 리뷰에 따르면 **"선수단과 개별 선수에게 더 세밀한 지시를 줄수록 '전술 복잡도'가 올라간다"**고 하며, 효율성은 훈련·조직력·능력치 뉘앙스·복잡도를 **함께** 따져 결정된다 [7]. 즉 **"더 정교하게 지시할수록 더 잘 된다"가 아니라 "정교함에 비용이 붙는다"**는 구조다. 이게 사실이라면 FM 시리즈가 수십 년간 유지한 "지시를 많이 아는 유저가 유리하다"는 **숙련도 보상 방향 자체를 뒤집은 것**이다. ⚠ **단일 출처**이며 수치 모델은 공개되지 않았다 — 분석 포인트 1·2가 전적으로 이 지점에 걸려 있다.
- **진행·성장 구조 (추정)**: 시즌 단위 루프 자체는 시리즈 전통과 같지만, **전술 효율성이 '시즌 중 전환'에 과도기 비용을 부과**한다는 서술이 일관된다. 인벤 글로벌은 **"완성한 전술을 여러 시즌 그대로 돌릴 수 없고, 작은 변경으로도 효율성이 흔들려 과도기가 생긴다"**고 적었고 [7], 유저들은 같은 현상을 **"시즌 중에 전술을 바꿀 수가 없다"**는 불만으로 표현했다 [13]. **설계 의도(실제 감독처럼 소통 과정을 표현)와 유저 체감(선택지 봉쇄)이 정확히 같은 메커니즘에서 갈린다.** 개발사는 구 시스템이 **"실제 감독이 선수단과 소통하는 과정을 표현하기에 한계가 있었다"**는 이유를 댔다 [8].
- **훈련의 위상 변화 (추정)**: 훈련이 '성장 관리'에서 **'전술 구현 수단'**으로 이동한 것으로 보인다. 인벤 글로벌 리뷰는 **하이 프레싱·후방 빌드업 같은 움직임별 1군 전용 세션이 추가**됐고, **조직력이 미숙하면 주간 훈련에 프레싱 세션을 배정해야 하며, 전술이 선수단 역량을 넘으면 지시를 줄이거나 더 좋은 선수를 구해야 한다**고 서술한다 [7]. GamingBolt도 **접근성 개선·일정 편성 개선·다음 경기 대비 중심·훈련 일정 복제 기능**을 꼽았다 [6]. 개발사는 **"훈련 변화와 함께 1군·유스·국가대표 관리의 갱신 요소들이 매끄럽게 엮이도록 했다"**고만 말했고 **구체 내용은 밝히지 않았다** [8].
- **UI 롤백 = 명시적 설계 후퇴 결정 (확인된 사실에 가까움)**: 공식 문서는 **타일의 주 용도를 '정보 표시'로 바꾸고 이동은 1·2차 메뉴로 모았으며**, 상위 메뉴를 **Portal / Squad / Tactics / Recruitment / Training / Club**으로 재명명하고 각 화면이 핵심 콘텐츠로 바로 열리게 했다고 설명한다. **주요 화면 상단 '컨트롤 패널'에 핵심 행동을 모았고**(예: Squad의 팀 미팅, Recruitment의 이적 예산 조정), **QHD·4K에서만 적용되는 3단 스케일링(Default/Detailed/Condensed)**, 울트라와이드 지원, 색상 코드가 적용된 메시지(스카우트 리포트·이적 제안을 메시지 안에서 바로 처리), 북마크 바, 단축키 재지정을 추가했다 [9]. 개발사는 UI 3원칙을 **효율성·친숙성·예측 가능성**으로 제시하며 **"올해는 UI 방향에 다소 보수적으로 접근하려 했다"**, **"기존 요소와 새 UI 사이의 적절한 중간 지점을 찾으려 했다"**고 말했다 [8].
- **BM / 수익 모델 (추정 아님, 확인됨)**: **₩69,800 단품 매절, 인앱 구매 없음** [1][3]. 수익화 요소는 **① 연간 신작 사이클(FM26 → FM27 풀프라이스 재구매) ② 별매 '게임 내 에디터' DLC $8.99 [3] ③ 무료 데모를 통한 전환 ④ Steam 창작마당 기반 모드 생태계**다. 인벤 글로벌 리뷰는 **AI 기반 도구를 포함한 모드 생태계**를 호평 항목으로 꼽았다 [7]. ⚠ 에디터 DLC가 FM26에도 별매였는지, 즉 '신규 분리 과금'인지는 확인하지 못했다. 유저 반발의 상당 부분이 **"업데이트로 줘야 할 것을 신작으로 팔았다"**는 ①에 걸려 있다 [13].
- **차별점 (유저·평론이 반복 언급하는 것)**: ① **전술 효율성/복잡도라는 '정교함에 비용을 매기는' 시스템** [6][7][8][12][13] ② **UI를 신작에서 되돌린 결정** [8][9][11] ③ **삭제됐던 분석 도구(히트맵·점유 범위·패스맵)의 1일차 복원** [7][11] ④ **경기 연출의 환경 시뮬레이션(실시간 날씨·시간대, 결과에 반응하는 관중)** [7] — 단 ④는 GamingBolt가 정반대로 혹평한 지점이다 [6].

## 플레이 계획

- **권장 플레이 시간: 총 35~45시간** (분석 포인트 8개 확인에 필요한 최소). 매니지먼트 장르라 1시즌이 15~20시간이고, **포인트 1·6은 시즌 단위 관찰이 아니면 측정이 불가능**하다. 표본 리뷰어들이 이미 70~190시간을 쌓은 장르라는 점도 감안해야 한다 [12][13].
- **확인 구간**
  1. **데모 1시간** — 포인트 7(온보딩). 구매 전에 먼저 한다.
  2. **본편 0~3시간 (하위 리그 신규 세이브)** — 포인트 2(복잡도 상한), 포인트 3(클릭 수). **이 구간은 되돌릴 수 없으므로 첫 30분을 반드시 기록하며 진행한다.**
  3. **3~12시간 (1시즌 전반기 ~ 겨울 이적시장)** — 포인트 1(전술 변경 비용), 포인트 4·5(경기 엔진·수비 AI, 전체 경기 보기).
  4. **12~20시간 (1시즌 후반기)** — 포인트 6(훈련 위임 비교), 포인트 8(에디터 없는 불편 지점).
  5. **20~40시간 (2시즌차 + 강팀 세이브)** — 포인트 1·2 재측정. **선수단을 전술에 맞춘 뒤에도 같은 비용이 붙는지**가 이 게임 평가의 갈림길이다.
- **구매 판단 근거 (유료 ₩69,800)**
  - **세일 없음** — 출시 7일차 할인 0% [1][2]이고, 연간 사이클 제품은 통상 다음 시즌까지 큰 할인이 없다. ⚠ 할인 이력은 확인하지 않았다.
  - **분석 가치는 높다고 본다.** 이 저장소 최초의 스포츠 매니지먼트 분석서이고, 무엇보다 **"전작 실패 → UI 롤백 → 평론 회복 → 유저 긍정률 역주행"이라는 구조가 7일치 수치로 남아 있는 표본**은 흔하지 않다. 포인트 1·2·5는 **다른 장르에 바로 응용되는 설계 질문**(정교함에 비용을 매기기, 시스템의 의도를 유저가 버그로 읽는 현상)이다.
  - **먼저 데모로 포인트 7을 확인하고 구매를 결정**하는 순서를 권한다 [3]. 데모에서 전술 효율성 화면까지 도달 가능하면 포인트 2의 예비 측정도 비용 0으로 가능하다.
